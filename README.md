# lace-dist — distribution for LACE

Artifacts for **LACE** (Lightweight Autonomous Coding Entities), an
experimental harness that runs coding agents through a Linear-issue →
session → draft-PR track. This repository is generated by CI on every
release; the only hand-written files are this README and LICENSE.

## Install (Linux)

```bash
curl -fsSL https://raw.githubusercontent.com/ildella/lace-dist/main/install.sh | bash
```

Needs Node ≥ 22.19 and nothing else — no clone, no yarn, no npm install.
The bootstrap verifies the tarball against `SHA256SUMS` before running
anything. macOS: coming in a next release.

LACE is in **closed testing**: expect sharp edges. It installs CLI bins
in `~/.local/bin`, skills in `~/.agents/skills/`, agent definitions into
your harness configs (opencode et al.), and an opencode sidebar plugin.

## Configure

Dispatch verbs need a Linear API key: set `LINEAR_API_KEY` in the
environment or `issues.linear.apiKey` in `~/.config/lace/lace.jsonc`.

## Uninstall

```bash
node ~/.lace/uninstall
```

## Versioning

Tagged releases here (`v0.6.0`, …); `install.sh` always points at the
latest release. Source is not published in this phase — see
[LICENSE](LICENSE).
